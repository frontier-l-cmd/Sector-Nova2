*Subtitle: **ECLIPSE***

- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

## 起動方法

`index.html` をブラウザで開くだけで遊べます。ビルドは不要です。
ローカルサーバーを使う場合は、このフォルダで `python -m http.server 8754` を実行して
`http://localhost:8754/` を開いてください。

### オプション機・NOVA BURST・かすり・コンボ

- **オプション機**: 自機の左右後方に少し遅れてついてくる。自機と同じ武器を Lv1・威力50%で撃つ。自機が被弾すると1機減る
- **NOVA BURST**（X、ゲージ100%の時だけ）: 敵弾を全部消す（1発10点）/ 画面内の雑魚に30ダメージ / ボスへは最大HPの8%が上限 / 120フレーム無敵 / 白〜金のリングとフラッシュ
- **ゲージのたまり方**: 雑魚撃破 +2%（大型 +4%）/ かすり +3% / STAR CHIP +10% / Lv3 で同色 +15% / ボス部位破壊 +10%。被弾しても減らない
- **かすり**: 敵弾が自機の中心から 20px 以内を通ると、1発につき1回 ゲージ +3%・20点（コンボ倍率あり）・小さな火花。無敵中は発生しない
- **コンボ**: 90フレーム以内に次の敵を倒すと続く。時間切れか被弾で 0。0〜9 は ×1、10〜24 は ×2、25〜49 は ×4、50以上は ×8。撃破点・かすり点・部位破壊点にかかる

## 武器の1秒あたりダメージ（計測）

Phase 3 の前に、実際のゲームループで 20 秒間撃ち続けて計測しました（計測用に、動かない・倒れない的をスクリプトで置いて測定。ゲーム本体には入っていません）。
単位は「1秒あたりのダメージ」です。

- **遠距離**: ボスと同じ大きさの的（半径40px）を、自機の 280px 上に置く（ボスがいる画面上部を、下から撃つ時の距離）
- **近距離**: 同じ的を自機の 80px 上に置く（ボスに張り付いた時。全弾が当たるので理論上の最大値と同じ）
- **+OPT2**: オプション機2機（Lv1 相当・威力50%）を足した値

| 武器 | Lv | 遠距離 | 遠距離 +OPT2 | 近距離 | 近距離 +OPT2 |
|---|---|---|---|---|---|
| NORMAL | — | 7.4 | 14.7 | 7.5 | 15.0 |
| SPREAD FAN | 1 | 5.9 | 17.6 | 18.0 | 36.0 |
| SPREAD FAN | 2 | 11.8 | 23.5 | 24.0 | 42.0 |
| SPREAD FAN | 3 | 5.9 | 17.6 | 30.0 | **48.0** |
| RAIL LANCER | 1 | 9.9 | 19.8 | 10.0 | 20.0 |
| RAIL LANCER | 2 | 9.9 | 19.8 | 10.0 | 20.0 |
| RAIL LANCER | 3 | 19.8 | **29.7** | 20.0 | 30.0 |
| CHAIN BOLT | 1〜3 | 5.9 | 11.8 | 6.0 | 12.0 |
| HOMING NEEDLE | 1 | 4.2 | 8.3 | 4.3 | 8.6 |
| HOMING NEEDLE | 2 | 8.3 | 12.5 | 8.6 | 12.9 |
| HOMING NEEDLE | 3 | 12.5 | 16.6 | 12.9 | 17.2 |

読み方:

- SPREAD は遠距離だと外側の弾がボスから外れる（Lv3 の 5 方向は中央の1発しか当たらない）。近づくほど強い（設計書どおり）
- RAIL は Lv1 と Lv2 で威力が同じ（太さだけ変わる）。ボス相手には Lv3 の2本で倍になる
- CHAIN は1体相手だと Lv による差がない。群れ相手では1発ごとに「1 ＋ 連鎖 Lv 回」当たるので、
  80px 以内に敵が十分いれば Lv1 で 12、Lv2 で 18、Lv3 で 24（オプション2機で最大 +12）まで上がる
- 最強は **近距離の SPREAD Lv3 ＋ オプション2機（48）**、遠距離なら **RAIL Lv3 ＋ オプション2機（29.7）**

## ボスの撃破時間（Phase 4-1、自動テストで実戦計測）

### ダメージ上限の値（Phase 4-1 で確定: 8）

「上限を超えた分は半分だけ効く」なので、強い装備ほど「素の1秒あたりダメージの半分＋上限の半分」に近づきます。
上限を NORMAL の1秒あたりダメージ（約 7.5）より下げると NORMAL まで遅くなるため、**NORMAL より少し上**が目安です。

| ボス | 値（確定） | 理由 |
|---|---|---|
| GLACIER MAW | **上限 8 / HP 200** | 最強装備 15秒以上に余裕を持たせるため HP 196 → 200 に変更（検収時の指示）。上限 6 や 5 だと NORMAL が 59〜69秒に伸び、上限 9〜10 だと最強が 13秒台になる |
| FROST SENTINEL | **上限 8 / HP 60（設計書どおり）** | NORMAL を遅くしない値。ただし最強装備では上限をいくつにしても 3〜4秒で溶ける（上限 4 でも 3.5秒）。HP 60 が小さいため |

調べた組み合わせ（GLACIER MAW。NORMAL 遠 / SPREAD Lv2 近 / SPREAD 最強 近 / RAIL 最強 遠、秒）:

**決定済み**: 上限 8（DESIGN.md 14 に明記）、GLACIER MAW の HP 200。

**残りの要判断**

2. 「無理なく持てる装備」で CHAIN Lv2（55〜57秒）と HOMING Lv2（51〜52秒）は 45 秒を超えます。
   CHAIN は1体相手だと連鎖しない、HOMING は1発が軽い武器なので、ボス相手に弱いのは武器の性格どおりと考えて、そのままにしています。
   全武器を45秒以内にするなら HP を下げることになり、最強 15 秒以上と両立しません。
3. FROST SENTINEL: 設計書に想定撃破時間がありません。最強装備で 3〜4 秒です。案:
   - (a) このまま（中ボスはすぐ倒せてよい。逃げる 25 秒までに NORMAL でも倒せる）
   - (b) 想定撃破時間を「10〜20秒」と決め、HP を約 130 に上げる（NORMAL は 25 秒の逃走時間を超えそうなので、逃走時間も見直しが必要）

## 仕組み（開発者向け）

### タイムライン（`src/timeline.js`）

ステージの敵出現とイベントを時刻付きのデータで書きます。

```js
{ t: 2.0,   spawn: 'A', x: 80, count: 3, interval: 20, pattern: 'line' },
{ t: 108.0, event: 'warning' },
{ t: 111.0, event: 'boss', type: 'orbCore' },
```

- `x`: 数値（px）または `'left' | 'center' | 'right' | 'random' | 'player'`
- `pattern`: `line`（同じ位置から順番に）/ `wave`（同じ波を描く）/ `column`（縦に並んで同時）/
  `row`（横一列）/ `v`（V字編隊）/ `sides`（左右の端から交互）/ `random`（1体ごとにランダム）
- `spacing`: row / column / v の間隔（px、省略時 30）
- `TimelineRunner` は独自の時計を持ち、`pause()` 中は後続のイベントが止まります（中ボス戦用）
- `DEBUG_MODE` 時、起動時にタイムラインの書き間違い（未知の敵・イベント・ボス、ボス無し）を `console.warn` で知らせます

### ボス（`src/boss.js` + `src/bosses/*.js`）

ボスは `BossBase` を継承して1ファイルずつ作ります。`BossBase` が受け持つもの:

- `phases`: 形態（名前、形態ごとの HP、移行条件 `endAtHpRatio` / `endWhen`、攻撃リスト、`onEnter`）
- `parts`: 部位（`BossPart`。コアより先に当たり、壊れると得点・再生も可）
- `isVulnerable()` / `damageMultiplier()`: 弱点露出・ダメージ軽減
- 攻撃スケジューラ: `{ run, duration, rest }` を順番に繰り返す
- 形態移行: 敵弾と危険物を全消去し、形態名を2秒表示
- 撃破: 揺れながら小爆発（90f）→ 大爆発・弾消去 → 2秒の余韻 → ステージ終了
- 50% 以下で `isEnraged`
- `damageCap`: 1秒あたりダメージのゆるい上限。直近 60 フレームに受けた量が上限を超えた分は半分だけ効く（NOVA BURST は対象外。部位にも適用）
- `midboss` / `escapeAfter`: 中ボス。時間切れで上へ逃げ、得点なしで終わる

### 弾パターン（`src/patterns.js`）

- `Patterns.aimed / fan / ring / spiral / burstFromDeath` が弾の配列を返します
- 難易度の倍率と弾速の上限（NORMAL で 4.0）は **ここだけ** で適用します
- `Hazard`: 予告（最低40フレーム、点滅する細い線）→ 発動（当たり判定あり）の2段階。
  形は `vline`（縦の雷）/ `hline`（横のフレア）/ `beam`（レーザー、回転可）/ `circle`

### Phase 3 前の計測で分かったこと（武器の強さ）

「武器の1秒あたりダメージ（計測）」のとおり、最強装備（近距離 SPREAD Lv3 ＋ オプション2機で 48）は、
設計書の HP の目安だとルールの上限（9〜14）の3〜5倍です。**数値は変えていません。** 判断材料と案:

- 新しいルールは「最強装備でも、想定撃破時間の下限の半分以上」＝「最強装備は、想定撃破時間の基準の装備より最大2倍までしか速く倒せない」という意味になります。
- S2 以降の基準は「Lv2 武器」。一番強い Lv2（SPREAD Lv2 近距離 24）で HP を決めれば、最強装備 48 はちょうど2倍で、ルールの境目に収まります。
  → **案1: Phase 4/5 でボスの HP を「SPREAD Lv2 の近距離で想定撃破時間の下限」になるように決め直す**（例: THUNDER RAY は 24×50秒 = 1200 前後）。
- S1 の基準は NORMAL（7.5）なので、最強装備（48）は 6.4倍。HP 調整だけではルールを守れません。
  → **案2: ボスが1秒あたりに受けるダメージに上限を付ける**（例: 基準の装備の2倍まで。雑魚相手の爽快感はそのまま）。
  → **案3: 武器側を弱める**（オプションの威力 50%→25%、SPREAD Lv3・RAIL Lv3 の威力を下げる など）。全体の手触りが変わります。
- おすすめは **案1 ＋ 案2**（武器の気持ちよさを残し、どのボスでもルールを確実に守れる）。採用するかはご判断ください。
