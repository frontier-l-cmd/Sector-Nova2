# SECTOR NOVA 2

*Subtitle: **ECLIPSE***

SFC（スーパーファミコン）風の縦スクロールシューティング「SECTOR NOVA」の続編です。
HTML5 Canvas と JavaScript だけで作られており、画像・音声ファイル・外部ライブラリは使いません。

- 設計書: [DESIGN.md](DESIGN.md)（開発は「16. 開発フェーズ」の Phase 単位で進めます）
- 見た目のルール: [STYLE_GUIDE.md](STYLE_GUIDE.md)
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)
- 1作目（`../sector-nova/`）は一切変更していません。

## 現在のバージョン: Phase 2（自機と新システム）

Phase 2 で自機・武器・アイテム・新システムが2作目のものになりました。雑魚とボスはまだ1作目のもの（仮）です。

- 新自機 **NOVA-II**（細身の双発機）とオプション機（最大2機）
- 武器: NORMAL + SPREAD FAN / RAIL LANCER / CHAIN BOLT / HOMING NEEDLE（Lv1〜3、時間切れなし）
- **NOVA BURST**（X）、**かすり**、**コンボ**（×1 / ×2 / ×4 / ×8）
- アイテム全10種（NOVA CRYSTAL は見た目と取得処理まで）、REFLECT SHIELD の弾反転
- HUD 一式（コンボ・結晶数・武器 Lv・オプション・NOVA ゲージ）、デバッグキー 1〜9 / 0
- 効果音: ショット・被弾・撃破・アイテム・かすり・BURST

### Phase 1 で作ったもの

- 新しいタイトルメニュー（↑↓で選択、←→で変更、Enterで決定）
- Stage 1「FROST RING」が **タイムライン** で進行（敵は1作目のものを使った仮配置）
- Stage 1 のボスは、`BossBase` で作り直した **ORB CORE**（1作目と同じ HP・攻撃・見た目）
- 弾パターン関数と予告付き危険物 `Hazard`（`src/patterns.js`）
- HUD とメニューを `game.js` から分離（`src/hud.js` / `src/menu.js`）
- Web Audio の骨組み（最初のキー入力で起動、M でミュート、テスト用効果音3つ）
- 背景モジュールの骨組み（ステージ別テーマ。Stage 1 は氷の青）
- セーブは `sectorNova2_*` キー（1作目とは完全に別）

## 起動方法

`index.html` をブラウザで開くだけで遊べます。ビルドは不要です。
ローカルサーバーを使う場合は、このフォルダで `python -m http.server 8754` を実行して
`http://localhost:8754/` を開いてください。

## 操作

| キー | 動作 |
|---|---|
| 矢印キー / WASD | 移動 |
| Space | ショット（押しっぱなしで連射） |
| P | ポーズ / 再開 |
| Enter | 決定 / 進む / タイトルへ戻る |
| M | サウンドの ON / OFF（どの画面でも可） |
| タイトル: ↑↓ | メニュー選択 |
| タイトル: ←→ | DIFFICULTY / STAGE SELECT / SOUND の値を変更 |
| タイトル: C | CONTINUE（最新の解放ステージから） |
| タイトル: 1〜6 | 解放済みのステージを直接開始（Phase 1 は Stage 1 のみ） |
| X | NOVA BURST（ゲージ満タン時のみ） |

### テスト用の仮タッチ操作（本格的なスマホ対応は対象外）

| 画面 | 操作 |
|---|---|
| タイトル | 行をタップで選択、選択中の行をもう一度タップで決定（DIFFICULTY / SOUND はタップごとに切り替え） |
| プレイ中 | 画面のどこでもドラッグで移動（相対移動）、触れている間は自動ショット、2本指タップでポーズ |
| プレイ中（右下の BURST ボタン） | ゲージ満タンの時だけ金色に光って押せる。満タン前は暗い丸で、縁にゲージの溜まり具合が出る（押しても何も起きない）。移動中の指と同時に押せる |
| ポーズ中 | タップで再開 |
| その他の画面 | タップ = Enter |

`src/touch.js` に分離しています。BURST ボタンはタッチ操作ができる端末でだけ表示されます（PC では出ません）。
設計書の「2. 変える」に「テスト用の仮タッチ操作あり（本格的なスマホ対応は対象外）」と記載し、各 Phase の完了条件の確認に含めます。

### デバッグキー（`DEBUG_MODE = true` の時、プレイ中のみ）

| キー | 動作 |
|---|---|
| 1〜4 | 武器を SPREAD / RAIL / CHAIN / HOMING に切り替え（Lv はそのまま。NORMAL からなら Lv1） |
| 5 | 現在の武器の Lv +1（最大3。NORMAL の時は何もしない） |
| 6 | オプション機 +1（最大2） |
| 7 | REFLECT SHIELD 付与 |
| 8 | NOVA ゲージを満タン |
| 9 | WARNING の直前までスキップ（ボス戦の確認用） |
| 0 | 無敵の ON / OFF（右下に INVINCIBLE と表示。かすりは発生する） |

`DEBUG_MODE` の時は、画面右下（NOVA ゲージの上）にタイムラインの経過秒と敵・敵弾の数が出ます。
ブラウザのコンソールから `window.game` でゲームの状態を確認できます。
リリース時は `src/utils.js` の `DEBUG_MODE` を `false` にしてください。

### オプション機・NOVA BURST・かすり・コンボ

- **オプション機**: 自機の左右後方に少し遅れてついてくる。自機と同じ武器を Lv1・威力50%で撃つ。自機が被弾すると1機減る
- **NOVA BURST**（X、ゲージ100%の時だけ）: 敵弾を全部消す（1発10点）/ 画面内の雑魚に30ダメージ / ボスへは最大HPの8%が上限 / 120フレーム無敵 / 白〜金のリングとフラッシュ
- **ゲージのたまり方**: 雑魚撃破 +2%（大型 +4%）/ かすり +3% / STAR CHIP +10% / Lv3 で同色 +15% / ボス部位破壊 +10%。被弾しても減らない
- **かすり**: 敵弾が自機の中心から 20px 以内を通ると、1発につき1回 ゲージ +3%・20点（コンボ倍率あり）・小さな火花。無敵中は発生しない
- **コンボ**: 90フレーム以内に次の敵を倒すと続く。時間切れか被弾で 0。0〜9 は ×1、10〜24 は ×2、25〜49 は ×4、50以上は ×8。撃破点・かすり点・部位破壊点にかかる

## 武器の1秒あたりダメージ（計測）

Phase 3 の前に、実際のゲームループで 20 秒間撃ち続けて計測しました（計測用に、動かない・倒れない的をスクリプトで置いて測定。ゲーム本体には入っていません）。
単位は「1秒あたりのダメージ」です。

- **遠距離**: ボスと同じ大きさの的（半径40px）を、自機の 280px 上に置く（ボスがいる画面上部を、下から撃つ時の距離）
- **近距離**: 同じ的を自機の 80px 上に置く（ボスに張り付いた時。全弾が当たるので理論上の最大値と同じ）
- **+OPT2**: オプション機2機（Lv1 相当・威力50%）を足した値

| 武器 | Lv | 遠距離 | 遠距離 +OPT2 | 近距離 | 近距離 +OPT2 |
|---|---|---|---|---|---|
| NORMAL | — | 7.4 | 14.7 | 7.5 | 15.0 |
| SPREAD FAN | 1 | 5.9 | 17.6 | 18.0 | 36.0 |
| SPREAD FAN | 2 | 11.8 | 23.5 | 24.0 | 42.0 |
| SPREAD FAN | 3 | 5.9 | 17.6 | 30.0 | **48.0** |
| RAIL LANCER | 1 | 9.9 | 19.8 | 10.0 | 20.0 |
| RAIL LANCER | 2 | 9.9 | 19.8 | 10.0 | 20.0 |
| RAIL LANCER | 3 | 19.8 | **29.7** | 20.0 | 30.0 |
| CHAIN BOLT | 1〜3 | 5.9 | 11.8 | 6.0 | 12.0 |
| HOMING NEEDLE | 1 | 4.2 | 8.3 | 4.3 | 8.6 |
| HOMING NEEDLE | 2 | 8.3 | 12.5 | 8.6 | 12.9 |
| HOMING NEEDLE | 3 | 12.5 | 16.6 | 12.9 | 17.2 |

読み方:

- SPREAD は遠距離だと外側の弾がボスから外れる（Lv3 の 5 方向は中央の1発しか当たらない）。近づくほど強い（設計書どおり）
- RAIL は Lv1 と Lv2 で威力が同じ（太さだけ変わる）。ボス相手には Lv3 の2本で倍になる
- CHAIN は1体相手だと Lv による差がない。群れ相手では1発ごとに「1 ＋ 連鎖 Lv 回」当たるので、
  80px 以内に敵が十分いれば Lv1 で 12、Lv2 で 18、Lv3 で 24（オプション2機で最大 +12）まで上がる
- 最強は **近距離の SPREAD Lv3 ＋ オプション2機（48）**、遠距離なら **RAIL Lv3 ＋ オプション2機（29.7）**

## 仕組み（開発者向け）

### タイムライン（`src/timeline.js`）

ステージの敵出現とイベントを時刻付きのデータで書きます。

```js
{ t: 2.0,   spawn: 'A', x: 80, count: 3, interval: 20, pattern: 'line' },
{ t: 108.0, event: 'warning' },
{ t: 111.0, event: 'boss', type: 'orbCore' },
```

- `x`: 数値（px）または `'left' | 'center' | 'right' | 'random' | 'player'`
- `pattern`: `line`（同じ位置から順番に）/ `wave`（同じ波を描く）/ `column`（縦に並んで同時）/
  `row`（横一列）/ `v`（V字編隊）/ `sides`（左右の端から交互）/ `random`（1体ごとにランダム）
- `spacing`: row / column / v の間隔（px、省略時 30）
- `TimelineRunner` は独自の時計を持ち、`pause()` 中は後続のイベントが止まります（中ボス戦用）
- `DEBUG_MODE` 時、起動時にタイムラインの書き間違い（未知の敵・イベント・ボス、ボス無し）を `console.warn` で知らせます

### ボス（`src/boss.js` + `src/bosses/*.js`）

ボスは `BossBase` を継承して1ファイルずつ作ります。`BossBase` が受け持つもの:

- `phases`: 形態（名前、形態ごとの HP、移行条件 `endAtHpRatio` / `endWhen`、攻撃リスト、`onEnter`）
- `parts`: 部位（`BossPart`。コアより先に当たり、壊れると得点・再生も可）
- `isVulnerable()` / `damageMultiplier()`: 弱点露出・ダメージ軽減
- 攻撃スケジューラ: `{ run, duration, rest }` を順番に繰り返す
- 形態移行: 敵弾と危険物を全消去し、形態名を2秒表示
- 撃破: 揺れながら小爆発（90f）→ 大爆発・弾消去 → 2秒の余韻 → ステージ終了
- 50% 以下で `isEnraged`

### 弾パターン（`src/patterns.js`）

- `Patterns.aimed / fan / ring / spiral / burstFromDeath` が弾の配列を返します
- 難易度の倍率と弾速の上限（NORMAL で 4.0）は **ここだけ** で適用します
- `Hazard`: 予告（最低40フレーム、点滅する細い線）→ 発動（当たり判定あり）の2段階。
  形は `vline`（縦の雷）/ `hline`（横のフレア）/ `beam`（レーザー、回転可）/ `circle`

   Phase 4 でリザルト画面、Phase 5 でエンディングに置き換え、BEST CLEAR の記録も NORMAL END 到達時に変えます。
3. **DIFFICULTY は選択とセーブのみ。** 弾速・発射頻度の倍率は Phase 3 で `patterns.js` の `patternDifficulty()` に、
   初期ライフ・ゲージ・スコア倍率は Phase 6 で適用します（倍率表は `DIFFICULTY_SETTINGS` に定義済み）。
4. **←→ は DIFFICULTY 行以外でも使います。** STAGE SELECT 行では ←→ でステージ番号、SOUND 行では ON/OFF を切り替えます。
   DIFFICULTY / SOUND 行は Enter でも切り替わります。（Phase 2 開始時に DESIGN.md「3. 操作」へ反映済み）
5. **タイトルの Enter は「選択中の項目の決定」。** カーソルの初期位置は NEW GAME なので、1作目と同じく Enter だけで開始できます。

   赤い帯・警報音・BGM 切り替えは Phase 4。
8. **デバッグキーは暫定。** 1作目の 1〜5（武器/シールド）を残し、タイムライン仕様にある 9（WARNING 直前へ）だけ追加しました。

### Phase 2 で判断したこと

1. **「大型の敵」（ゲージ +4%）は半径 13px 以上の敵** としました（`LARGE_ENEMY_RADIUS`）。今の仮の敵では C・SHIELD・SPLIT・TURRET が該当します。Phase 3 で敵ごとに見直します。
2. **武器アイテムを取った時の得点は無し**（Lv3 で同色の 5000点だけ）。1作目は 500点でしたが、設計書に記載がないため付けていません。
3. **コンボ倍率がかからないもの:** ボス撃破点（5000）、ボスへの命中点（1発10点）、BURST の弾消し点（1発10点）、アイテムの得点。
4. **BURST で倒した雑魚は、コンボは続きますがゲージは増えません**（BURST の連発を防ぐため。DESIGN.md「7. NOVA BURST」に追記済み）。得点とアイテムドロップは通常どおり。
5. **BURST のボスへのダメージ** は「30 と ボス最大HPの8% の小さい方」。コアにだけ当たり、部位には当たりません。ボスのダメージ倍率（顎を閉じている時の20% など）はかかります。
6. **CHAIN BOLT の電撃は雑魚の間だけ飛びます。** ボスに当たった時は威力1のみで連鎖しません。
7. **HOMING NEEDLE の目標** は画面内の一番近い雑魚、またはボスのコア（攻撃が通る時だけ）。
8. **REFLECT SHIELD で防いだ直後は 90 フレーム無敵**（1作目のシールドと同じ。続けて当たらないように）。この間はかすりも発生しません。跳ね返した弾の威力は 1 です。
9. **かすりは「当たっていないフレーム」に判定** します。弾が自機に当たる直前のフレームでかすりが入ることがあります（その後の被弾でコンボは切れます）。
10. **デバッグキー 1〜4 は Lv を引き継ぎます**（NORMAL からなら Lv1）。**0 の無敵中もかすりは発生します**（かすりの確認用）。
11. **HUD の追加・変更:** 左下に REFLECT SHIELD の残り秒を表示（15-4 の表にはない項目）。右上はステージを `ST1` と短く表示して結晶数と並べ、
    ボスの HP バーは右上のコンボ表示と重ならないよう左寄せで短くしました。満タン時の表示は `BURST READY [X]`。
12. **NOVA CRYSTAL の数は、CONTINUE / STAGE SELECT で始めたプレイではグレー表示** にしています（13. 隠し要素の表示ルール。TRUE END の判定自体は Phase 6）。
13. **アイテムのドロップ率は 12%、重みは STAR CHIP 40% / 武器 各8〜10% / OPTION 6% / REFLECT 8% / REPAIR 7% / HULL UP 5%**（設計書に数値がないため仮の値）。
14. **オプション機の弾（威力0.5）** は、1作目の SHIELD 敵には最低1ダメージとして当たります（仮の敵の仕様。Phase 3 で敵ごと置き換え）。
15. **難易度によるゲージのたまり方・スコア倍率は Phase 6 で適用**（今は NORMAL の値）。
