## 1. コンセプト

**「攻めるほど稼げて、ギリギリで避けるほど強くなる」SFC風縦シューティング。**

1作目から大きく変える3点:

1. **敵の出し方** — ランダム湧きをやめ、ステージごとに出現順を設計した「タイムライン型」にする。緩急・見せ場・中ボスを意図的に配置する。
2. **ボス** — 色違いの使い回しをやめ、1体ずつ形も攻撃も別物にする。多段階（フェーズ）・部位破壊・弱点露出を導入する。
3. **音と背景** — Web Audio APIで効果音とBGMを生成する（音声ファイルなし）。背景はステージ別に描き分ける。

プレイの循環:

- 連続撃破 → **コンボ倍率**でスコアが伸びる（攻め）
- 敵弾をギリギリで避ける → **かすり**でゲージがたまる（度胸）
- ゲージ満タン → **NOVA BURST**で危機を切り抜ける（判断）

## 2. 継承するもの / 変えるもの

### 継承する（1作目のルールをそのまま守る）

- 内部解像度 **320 × 480**、`image-rendering: pixelated` で拡大表示
- **Canvas 2D描画のみ**。画像・SVG・スプライトシート・外部フォントは使わない
- **外部ライブラリなし**。`<script>` タグを依存順に読み込む方式
- フォントは monospace のみ。ゲーム内テキストは英語（SFC風の雰囲気を優先）
- 60fps前提のフレームベース処理（`this.frame++`）
- UIはすべてCanvas内に描画（DOMのHUDは作らない）
- 色は `COLORS` に集約。エフェクトは `EffectsManager` を拡張して使う
- セーブは `localStorage`（外部ファイルは作らない）
- 基本操作（移動・ショット・ポーズ・Enter）
- 1作目の `STYLE_GUIDE.md` の思想（サイズ帯、発光表現、パレットの考え方）

### 変える

- 世界観、自機デザイン、全武器、全アイテム、全雑魚敵、全ボス、全ステージ
- 敵の出現方式（ランダム → タイムライン）
- 武器の仕組み（20秒時間制 → レベル制）
- 新システム: NOVA BURST、かすり、コンボ、オプション機、クリアランク
- 音（新規）、ステージ別背景（新規）、タイトルメニュー、難易度、やり込み要素
- テスト用の仮タッチ操作あり（本格的なスマホ対応は対象外）

### この版でやらないこと

- 画像素材・外部ライブラリの導入
- オンラインランキング
- 自機の機体選択

## 4. 世界観

### あらすじ

NEBULA HEARTの撃破から数か月。星系の中心にある恒星 **HELIOS** が、黒い影に蝕まれ始めた。
犯人は恒星のエネルギーを喰う機械生命体 **ECLIPSE**。このまま喰われ尽くせば、HELIOSは不安定化し、星系ごと消し飛ぶ。
新型機 **NOVA-II** は、星系の外縁から恒星の中心へ向けて単機で突入する。

### 色の流れ

ステージが進むほど、**冷たい青 → 灰 → 紫 → 赤 → 灼熱のオレンジ → 白と金** へ変わる。プレイヤーが「恒星に近づいている」ことを色で感じられるようにする。

- オペレーター名: **LYRA**（母艦のナビゲーターAI）
- ステージ開始時に1〜2行、ボス出現前に1行の短い通信を表示する
- 表示は画面下部の通信ウィンドウ（Canvas描画）。1文字ずつ表示し、Enterで早送り。プレイは止めない
- 文章は `src/story.js` にまとめる

## 5. 自機 NOVA-II

- 1作目の自機より細身でシャープなシルエット。双発エンジン。色は青系を継承（`PLAYER_BODY` 系）
- 見た目約24px幅、当たり判定は半径6px（1作目と同じ）
- 移動速度4（1作目と同じ）。RAIL LANCER装備中のみ0.75倍
- ライフ3（最大5。HULL UPで当該ステージ中のみ増える）
- 被弾後の無敵 90フレーム（点滅）

### オプション機

- 白いOPTIONアイテムで自機の周りに小型機が付く。**最大2機**
- 自機の左右後方に追従（少し遅れてついてくる）
- 自機と同じ武器を撃つ（ただし威力50%、Lv1相当の弾数）
- 自機が被弾すると1機失う。オプション機自体に当たり判定はない

## 6. 武器システム（レベル制）

### 基本ルール

- 常に **NORMAL**（単発・直進）を持っている。NORMALにLvはない
- 武器アイテムを取ると、その武器に切り替わる。**時間切れはない**
- 同じ色を取ると **Lv1 → Lv2 → Lv3** に上がる
- 別の色を取ると武器は変わるが、**Lvはそのまま引き継ぐ**
- Lv3の時に同じ色を取ると、**5000点 + NOVAゲージ15%**
- **被弾するとLvが1下がる**。Lv1で被弾するとNORMALに戻る
- REFLECT SHIELDで防いだ被弾ではLvは下がらない

### 武器一覧

| 色 | 名前 | Lv1 | Lv2 | Lv3 | 特徴 |
|---|---|---|---|---|---|
| — | NORMAL | 単発直進 | — | — | 威力1、連射間隔8f |
| 橙 | SPREAD FAN | 3方向 | 4方向 | 5方向 | 1発威力1。近距離で強い。広範囲の雑魚処理向き |
| 青 | RAIL LANCER | 細いビーム | 太いビーム | 太いビーム2本 | 敵を貫通（1体に1回ヒット）。威力2。縦一列に強い。装備中は移動0.75倍 |
| 紫 | CHAIN BOLT | 連鎖1回 | 連鎖2回 | 連鎖3回 | 当たった敵から最も近い別の敵（80px以内）へ電撃が飛ぶ。威力1+連鎖1。群れに強い |
| 緑 | HOMING NEEDLE | 追尾弾1発 | 2発 | 3発 | 画面内の最も近い敵を追う。威力1。MIRRORの側面を取れる |

- 発射間隔・弾速・威力はすべて定数化する
- 武器ごとの見た目は1作目の発光表現（外側のにじみ＋明るい芯）を守る
- CHAIN BOLTの電撃はジグザグ線で描く（紫〜白）

## 7. NOVA BURST（ボム）

- **Xキー**で発動。ゲージ（0〜100%）が満タンの時のみ使える。ストックは1
- 効果:
  - 画面内の敵弾をすべて消す（消した弾は小さな得点に変換、1発10点）
  - 画面内の雑魚に30ダメージ
  - ボスへのダメージは **ボス最大HPの8%が上限**（ボムだけで倒せないようにする）
  - 120フレーム無敵
  - 演出: 自機から白〜金の大きなリングが広がる、画面フラッシュ、専用効果音
- 被弾してもゲージは減らない
- BURSTで倒した雑魚ではゲージは増えない（コンボは続く。BURSTの連発を防ぐため）
- HUD右下にゲージ表示。満タンで「BURST READY」が点滅

### ゲージのため方

| 行動 | 増加量 |
|---|---|
| 雑魚撃破 | +2%（大型の敵は+4%） |
| かすり | +3%（1発につき1回） |
| STAR CHIP取得 | +10% |
| Lv3で同色取得 | +15% |
| ボス部位破壊 | +10% |

## 8. かすり（グレイズ）

- 敵弾が自機の当たり判定の外側、**半径20px以内**を通過した時に発生
- 1発の弾につき1回だけカウント（弾に `grazed` フラグ）
- 効果: NOVAゲージ+3%、スコア+20（コンボ倍率がかかる）、自機の周りに小さな火花
- **無敵中（被弾後・NOVA BURST中）はかすりが発生しない**（ボム直後の稼ぎ防止）

---

## 9. コンボ

- 敵を倒してから **90フレーム（約1.5秒）以内** に次の敵を倒すとコンボが続く
- 時間内に倒せなかった場合、または被弾した場合はコンボ数が0に戻る
- 倍率:

| コンボ数 | 倍率 |
|---|---|
| 0〜9 | ×1 |
| 10〜24 | ×2 |
| 25〜49 | ×4 |
| 50以上 | ×8 |

- 倍率は撃破点、かすり点、部位破壊点にかかる
- HUD右上に「COMBO 23 ×2」のように表示。残り時間を細いバーで示す
- 倍率が上がった瞬間に小さな文字演出（「×4!」）

## 12. ステージ

### 共通

- 1ステージは **ボス出現まで約100〜120秒**。構成は「序盤 → 中盤（ギミック区間）→ 中ボス → 後半 → WARNING → ボス」
- 敵の出現は **タイムライン（`src/timeline.js` のデータ）** で管理する（仕様は「15-1」）
- 各ステージに **独自ギミックを1つ** 入れる。ギミックは必ず予告を出し、初見でも避けられるようにする
- ボス撃破 → リザルト画面（ランク）→ 次ステージの通信 → 次ステージ

### 一覧

| # | 名前 | テーマ色 | 主な敵 | ギミック | 中ボス | ボス |
|---|---|---|---|---|---|---|
| 1 | FROST RING | 氷の青・白 | SHARD, WISP, SNIPER | 撃つと割れる巨大隕石 | FROST SENTINEL | GLACIER MAW |
| 2 | DEAD HARBOR | 鉄の灰・青、黄色の警告灯 | +GUN DECK, MINE LAYER, CARRIER | 壁に挟まれた狭い通路 | HARBOR SENTINEL | DOCK TITAN |
| 3 | STORM VEIL | 紫がかった灰・雷の白 | +MIRROR, PHASE GHOST | 落雷と雲 | STORM SENTINEL | THUNDER RAY |
| 4 | ECLIPSE HIVE | 暗い赤紫・有機的 | +SWARM, LINK GUARD | 撃つと開く肉の壁の迷路 | HIVE SENTINEL | HIVE MOTHER |
| 5 | CORONA ZONE | 赤・オレンジ | +FLARE SPIRIT | 太陽フレアと熱の揺らぎ | CORONA SENTINEL | CORONA SERPENT |
| 6 | HELIOS CORE | 白・金 | 全種の混成 | 恒星の引力 | NEBULA HEART（侵食体） | ECLIPSE CROWN |

### ギミック詳細

**S1 巨大隕石**
- 半径28px、HP12。ゆっくり流れてくる。自機が触れるとダメージ
- 破壊すると5つの破片が放射状に飛ぶ。**破片は敵にだけダメージ（3）を与え、自機には当たらない**
- 狙い: 「隕石を壊して敵を巻き込む」気持ちよさを序盤で教える

**S2 狭い通路**
- 中盤の約15秒間、左右から壁がせり出し、通路になる。通路幅は最小140px
- 壁に触れるとダメージ＋押し戻し。壁にGUN DECKが埋め込まれている
- 壁の出現前に「CAUTION: NARROW PASSAGE」と表示

**S3 落雷と雲**
- 落雷: 縦の予告線が60f点滅 → 20fの雷が落ちる（当たるとダメージ）。同時に最大2本
- 雲: 半透明（不透明度0.7）の雲の帯が流れる。**雲の下で敵本体は隠れるが、敵弾は必ず雲の上に描く**（不公平にしない）

**S4 肉の壁の迷路**
- 中盤の約15秒間、肉の壁ブロック（1個HP3）が横一列に並んで降りてくる。列ごとに隙間の位置が違う
- 撃てば壊せる。壊さずに隙間を縫ってもよい。壁に触れるとダメージ
- **必ず通れる経路がある配置にする**（全部塞がる列は作らない）

**S5 太陽フレアと熱の揺らぎ**
- フレア: 横帯の予告（90f、赤く点滅）→ 高さ40pxの炎の帯が40fかけて画面を横切る。当たるとダメージ
- 熱の揺らぎ: **背景だけ**を行ごとに横へ揺らす。自機・敵・弾は揺らさない（当たり判定と見た目がずれないように）

**S6 恒星の引力**
- 画面上部中央へ向かって、自機が弱く引き寄せられる（毎フレーム0.3px、定数化）
- 引力の向きを示す光の粒が流れる
- ボス戦中は引力を止める

## 13. 隠し要素とエンディング

### NOVA CRYSTAL（隠しアイテム）

各ステージに1つ。条件を満たすと虹色の結晶が出現し、取ると獲得。HUD右上に獲得数を小さく表示。

| ステージ | 出現条件 |
|---|---|
| S1 | 中盤に1体だけ流れてくる **GOLD SHARD** を、出現から5秒以内に倒す |
| S2 | 通路の壁に1枚だけある **色の違うパネル** を撃って壊す |
| S3 | 雲の中に1体だけいる **GOLD GHOST** を、見えている間に倒す |
| S4 | 肉の壁の迷路で、**模様の違う壁ブロック** を壊す |
| S5 | CORONA SERPENTの **体節を全部壊してから** 頭を倒す |
| S6 | 中ボスNEBULA HEARTを **NOVA BURSTを使わずに** 倒す |

- TRUE ENDの条件は「**NEW GAMEから、CONTINUEを使わずに、6個すべて獲得**」してECLIPSE CROWNを倒すこと
- ステージセレクトやCONTINUEで始めたプレイでも結晶は出るが、TRUE END条件には数えない（HUDにグレーで表示）

### エンディング

| 種類 | 条件 | 内容 |
|---|---|---|
| NORMAL END | ECLIPSE CROWNを倒す | HELIOSが輝きを取り戻す。エンディングテキスト → 総合スコア → タイトルへ |
| TRUE END | 上記のTRUE END条件を満たしてECLIPSE CROWNを倒す | 続けて **TRUE ECLIPSE**（真の姿）戦 → 撃破で専用エンディング |
| BAD END | ECLIPSE CROWN最終形態の60秒制限を過ぎる | 画面が白く飛ぶ「SUPERNOVA」演出 → BAD END表示。ゲームオーバー扱い（スコア記録、CONTINUE可） |

### 難易度

| | EASY | NORMAL | HARD |
|---|---|---|---|
| 初期ライフ | 4 | 3 | 3 |
| 敵弾の速さ | ×0.8 | ×1.0 | ×1.15 |
| 敵の発射頻度 | ×0.75 | ×1.0 | ×1.3 |
| FLARE SPIRITの撃ち返し | なし | あり | 弾数1.5倍 |
| NOVAゲージのたまり方 | ×1.5 | ×1.0 | ×1.0 |
| スコア倍率 | ×0.5 | ×1.0 | ×1.5 |

- タイトルのDIFFICULTY行で選ぶ。選択はセーブする
- TRUE ENDはどの難易度でも到達可能

### BOSS RUSHモード

- NORMAL END（どの難易度でも）到達で解放
- ボス6体（＋NEBULA HEART）と連戦。ステージ間にリザルトなし、ボス間で武器・ライフは持ち越し
- 記録はクリアタイム（短いほど良い）

## 14. ボス・中ボス

### 共通ルール

- 見た目の基本は1作目と同じ「重ねた装甲＋回転する部品＋脈打つコア」。ただし **形は1体ずつ別物** にする
- HPは目安。**「想定撃破時間」に合うように調整する** のが優先
  - 想定撃破時間は「その時点で無理なく持てる武器（S1はNORMAL、S2以降はLv2武器）」で計測
- HP50%以下で強化（1作目のenrageを継承）
- **攻撃は必ず予告を出す**（レーザー・雷・突進・落下物）
- ボス撃破時: 大爆発 → 画面の敵弾消去 → 2秒の余韻 → リザルト
  - 撃破した瞬間にも敵弾を消す（爆発演出中に被弾しないようにするため）

### WARNING演出

- ボス出現前の3秒間、画面上下に赤い帯が流れ、中央で「WARNING」が点滅 → ボス名を表示
- 警報音を鳴らし、BGMをボス曲へ切り替える
- 演出開始時に雑魚の出現を止め、残っている敵弾を消す

### 中ボス SENTINEL（S1〜S5共通）

- 共通の型（六角形の機体、半径24px）をステージごとの色で塗り分ける
- 攻撃: 5方向の扇弾と12方向のリング弾を交互に
- HP: S1=60 → S5=120（ステージごとに+15目安）
- ステージの約50秒地点で出現。**25秒で倒せないと逃げる**（逃げた場合は撃破点なし）

### ボス一覧

| ステージ | ボス | HP目安 | 想定撃破時間 |
|---|---|---|---|
| S1 | GLACIER MAW | 160 | 30〜45秒 |
| S2 | DOCK TITAN | コア200＋腕60×2 | 45〜60秒 |
| S3 | THUNDER RAY | 240 | 50〜70秒 |
| S4 | HIVE MOTHER | 280（卵は各6） | 60〜80秒 |
| S5 | CORONA SERPENT | 頭320＋体節15×10 | 60〜80秒 |
| S6中 | NEBULA HEART（侵食体） | 200 | 30〜40秒 |
| S6 | ECLIPSE CROWN | 220×3形態 | 合計120〜150秒 |
| TRUE | TRUE ECLIPSE | 400 | 60〜90秒 |

### GLACIER MAW（S1）

- 形: 上下の顎を持つ巨大な氷の頭。口の奥にコア
- 口を閉じている間は、顎に当たってもダメージ20%
- 6秒周期で3秒間口を開く。開いている間はコアが露出してダメージ100%。口から5方向の扇弾
- つらら: 画面上から落ちてくる（落下地点に40fの影の予告）。撃てば壊せて、たまにSTAR CHIPを落とす
- HP50%以下: 口を開く時間が長くなる代わりに扇弾が2連射。つららが増える
- 役割: チュートリアル的なボス。「弱点が見えた時に撃つ」を教える

### DOCK TITAN（S2）

- 形: 横長の港湾作業ロボ（幅約120px）。左右に腕の砲台、中央にコア
- フェーズ1（腕あり）: 左右の腕が交互に自機狙いの3方向弾。コアへのダメージは30%
- 腕を壊すと: 腕が切り離されてゆっくり落下し、障害物になる（触れるとダメージ、撃つと壊せて得点）。部位破壊ボーナス10000点
- フェーズ2（両腕なし）: コアへのダメージ100%。撃ち落とせる遅い追尾ミサイル（HP1）4発＋12方向リング弾
- HP50%以下: 横移動が速くなり、ミサイルが6発

### THUNDER RAY（S3）

- 形: 巨大なエイ。翼の縁が帯電して光る
- 攻撃A 雷撃: 縦の予告線2〜3本 → 落雷
- 攻撃B 雲潜り: 雲に潜って影だけになる（この間は無敵）。自機のX座標付近に波紋の予告 → 画面下から上へ急上昇しながら通過（体当たり判定あり）→ 上部へ戻る
- 攻撃C 尾の拡散: 尾から7方向の扇弾
- 順番: A → C → B を繰り返す
- HP50%以下: 横向きの雷（横の予告線）を追加

### HIVE MOTHER（S4）

- 形: 膨らんだ腹部を持つ女王型。全体が脈打つ
- 4秒ごとに卵（HP6）を1個落とす。卵はゆっくり降り、5秒で孵化してHATCHLINGになる
- 攻撃: ゆっくり回転する螺旋弾
- HP50%以下: 卵を2個ずつ、孵化まで4秒、螺旋が2重
- 狙い: 「卵を潰すか、本体を急ぐか」の判断を迫る

### CORONA SERPENT（S5）

- 形: 頭＋体節10個の炎の蛇。画面内をS字に這う（体節は頭の通った軌跡をなぞる）
- 弱点は頭だけ。体節は自機の弾を受け止める（体節自体にはダメージが入る）
- 体節が順番に光り、光った節から自機狙い弾を1発
- 体節を壊すと蛇が短くなり、体節からの弾も減る。体節1個1000点、全破壊で20000点（NOVA CRYSTALの出現条件）
- HP50%以下: 移動が速くなり、頭から5方向の炎の扇弾

### NEBULA HEART（侵食体 / S6中ボス）

- 1作目の最終ボスが、黒と紫に侵食された姿で再登場（1作目 `boss.js` の描画を参考に、黒い亀裂と紫のオーラを足す）
- 攻撃: 1作目風の3方向弾＋12方向リング弾。HP50%以下で、侵食部から自機狙い弾
- 中ボスだが逃げない（倒すまで進まない）
- 撃破時のLYRA通信: "IT WAS ONLY A SHELL... SOMETHING BIGGER IS WAITING."

### ECLIPSE CROWN（S6 最終ボス）

- 形: 黒い球体のコアを、金色の王冠状の破片6枚が囲む。日食のように縁が白く光る
- **第1形態 CROWN**: 6枚の破片（各HP15）がコアの周りを回り、盾になる。壊しても8秒で再生。攻撃は全方位リング弾＋破片からの自機狙い弾
- **第2形態 ECLIPSE**: 画面が暗転し、自機の周り半径90pxだけが明るく見える。ボス本体はコアの光だけ見える。攻撃はゆっくりした2重螺旋弾と、予告付きの直線レーザー
  - **敵弾は暗闇でも必ず見えるように、明るい輪郭付きで暗闇の上に描く**
- **第3形態 SUPERNOVA**: 背景が赤く脈打ち、画面上部に **60秒のカウントダウン**。予告付きの回転レーザー＋扇弾＋リング弾（激しいが避けられる密度）。0になるとBAD END
- 形態が変わる時: 敵弾を全消去し、2秒間の演出（形態名を表示）

### TRUE ECLIPSE（TRUE END専用）

- ECLIPSE CROWN撃破後、TRUE END条件を満たしていれば出現
- 登場演出: 6個の結晶が自機の周りに現れ「LIGHT RESONANCE」と表示。この戦いの間、自機の武器は自動でLv3
- 攻撃: 歴代ボスの代表技を順番に使う（つらら → 追尾ミサイル → 雷 → 卵 → 体節弾）＋独自の全画面パターン
- 時間制限なし

## 15. 技術仕様

### 15-1. タイムライン（`src/timeline.js`）

ステージの敵出現・イベントを時刻付きのデータで書く。

```js
const STAGE_TIMELINES = {
  1: [
    { t: 2.0,   spawn: 'SHARD', x: 80,  count: 3, interval: 20, pattern: 'line' },
    { t: 6.0,   spawn: 'WISP',  x: 'left', count: 4, interval: 15, pattern: 'wave' },
    { t: 30.0,  event: 'asteroid', x: 160 },
    { t: 42.0,  event: 'goldEnemy', type: 'SHARD', x: 240 },   // NOVA CRYSTAL用
    { t: 50.0,  event: 'midboss', type: 'sentinel' },
    { t: 75.0,  event: 'comm', id: 's1_mid' },
    { t: 108.0, event: 'warning' },
    { t: 111.0, event: 'boss', type: 'glacierMaw' },
  ],
};
```

- `t` はステージ開始からの秒数（内部ではフレームに変換）
- **中ボス戦中はタイムラインを止める**（中ボスを倒すか逃げるまで進まない）
- イベントの種類: `spawn` / `midboss` / `boss` / `warning` / `comm` / `gimmickStart` / `gimmickEnd` / `hazard`（雷・フレア）/ `asteroid` / `goldEnemy` / `wall`（通路・肉の壁）
- `x` は数値（px）または `'left' | 'center' | 'right' | 'random' | 'player'`
- `pattern` は出現の並び方（`line` / `wave` / `v` / `column` / `sides` など）
- デバッグキー9で `warning` の直前へジャンプできるようにする
- `DEBUG_MODE` 時のみ、タイトルから **Stage 0「TEST RANGE」**（全雑魚を順番に出す確認用ステージ）を選べるようにする

### 15-2. ボスの枠組み（`src/boss.js` ＋ `src/bosses/*.js`）

- 共通の親クラス `BossBase` を作り、ボスごとに1ファイルで継承する
- `BossBase` が持つもの:
  - `phases`: 形態のリスト（名前、移行するHP、使う攻撃、移行時の処理）
  - `parts`: 部位のリスト（位置、半径、HP、壊れた時の処理）
  - `isVulnerable()` / `damageMultiplier()`: 弱点露出・ダメージ軽減の判定
  - 攻撃パターンのスケジューラ（攻撃の順番、継続時間、間隔）
  - 形態移行時の共通処理（敵弾全消去、形態名表示）
  - 撃破時の共通処理（大爆発、弾消去、余韻）
- 1作目のORB COREを `BossBase` で作り直して動作確認に使う（Phase 1）

### 15-3. 弾パターンと危険物（`src/patterns.js`）

- 共通関数: `aimed`（自機狙い）/ `fan`（扇）/ `ring`（全方位）/ `spiral`（螺旋）/ `burstFromDeath`（撃ち返し）
- 難易度の倍率（弾速・発射頻度）は **この関数の中で一括適用** する
- 敵弾の速さの上限を定数で持つ（NORMALで4.0目安）
- 弾の種類と色:
  - 通常の敵弾: 赤（1作目と同じ）
  - ボス弾: オレンジ（1作目と同じ）
  - 撃ち返し弾: ピンク、遅い
  - 反射弾（REFLECT SHIELD・MIRROR）: 水色〜白。REFLECT由来は敵に当たる、MIRROR由来は自機に当たる
- レーザー・雷・フレア・つららなどは「予告 → 発動」の2段階を持つ `Hazard` クラスで共通化する

| 左上 | ライフ（アイコン） |
| 上中央 | スコア |
| 右上 | ステージ番号、コンボ数と倍率、コンボ残り時間バー、NOVA CRYSTAL獲得数 |
| 上部（ボス戦中） | ボス名とHPバー。最終ボスは形態名、第3形態は60秒カウントダウン |

### 15-5. 画面の流れ（状態）

- TITLE → OPENING（あらすじ通信）→ STAGE_INTRO（ステージ名表示＋通信）→ PLAYING（WARNING・中ボス・ボスを含む）→ STAGE_RESULT → 次のSTAGE_INTRO …
- そのほか: PAUSED / GAME_OVER / ENDING（NORMAL / TRUE / BAD）/ BOSS_RUSH / BOSS_RUSH_RESULT
- タイトルメニュー（↑↓で選択、Enterで決定）:
  - NEW GAME
  - CONTINUE（最新の解放ステージから）
  - STAGE SELECT（解放済みのみ）
  - DIFFICULTY: EASY / NORMAL / HARD（←→で変更）
  - BOSS RUSH（未解放時は「???」でグレー表示）
  - SOUND: ON / OFF
- タイトルにはロゴ「SECTOR NOVA 2」、サブタイトル「ECLIPSE」、BEST SCORE、BEST CLEARを表示

### 15-6. リザルトとクリアランク

ステージクリア時に表示: クリアタイム、被弾数、最大コンボ、部位破壊ボーナス、ランク、合計

ランクは100点満点で計算:

| 項目 | 配点 |
|---|---|
| 被弾数 | 0回=40 / 1回=25 / 2回=10 / 3回以上=0 |
| ボス撃破タイム | 想定撃破時間の下限以内=30 / 上限以内=15 / それ以上=0 |
| 最大コンボ | 50以上=30 / 25以上=20 / 10以上=10 / それ未満=0 |

| ランク | 点数 | ボーナス |
|---|---|---|
| S | 90以上 | 50000 |
| A | 70以上 | 30000 |
| B | 45以上 | 10000 |
| C | それ未満 | 0 |

ボーナスには難易度のスコア倍率をかける。

### 15-7. ステージ開始時のルール

- **通常進行（クリアして次へ）で引き継ぐ**: スコア、武器とLv、オプション機、NOVAゲージ、NOVA CRYSTAL
- **毎ステージ戻す**: ライフ（難易度の初期値へ）、HULL UPの上限、REFLECT SHIELD、自機の位置（下中央）、短い無敵
- **CONTINUE / STAGE SELECTで始めた場合**: スコア0、NORMAL、オプションなし、ゲージ0
- ゲームオーバー → タイトルへ。CONTINUEで最新の解放ステージから再開（1作目と同じ）

### 15-8. サウンド（`src/audio.js`）

- Web Audio APIで **すべて生成**（音声ファイルは使わない）。矩形波・三角波・ノイズでSFC風の音を作る
- ブラウザの自動再生制限のため、**最初のキー入力で AudioContext を作る**
- Mキーでミュート切り替え。設定はセーブする
- 効果音: ショット（小さく、鳴らしすぎない間引きあり）、被弾、敵撃破（小・大）、アイテム取得、Lvアップ、かすり、NOVA BURST、WARNING警報、ボス撃破、形態移行、通信の文字送り、メニュー移動・決定、NOVA CRYSTAL取得
- BGM: タイトル、各ステージ（制作量が多い場合は2ステージで1曲を共有してよい）、ボス、最終ボス、ステージクリア、ゲームオーバー、エンディング
- BGMは簡単なステップシーケンサーで鳴らす。曲データは音名の配列で `audio.js` 内に持つ
- 音量の目安: 全体0.3、BGMは効果音より小さめ

| ステージ | 背景 |
|---|---|
| S1 | 氷の青い星空、漂う氷の粒、遠くに環のある惑星 |

## 17. バランスの原則

- **S1はNORMALだけでクリアできる**
- **危険なものには必ず予告を出す**（最低40フレーム）
- **敵弾を隠さない**（雲・暗闇・明るい背景の上でも必ず見える）
- **避けられない配置を作らない**。難しさは弾の量ではなく、敵の組み合わせと判断で作る
- 被弾後の無敵は90フレーム、NOVA BURST後は120フレーム
- 調整用の数値はすべて定数化する
- 目標性能: 敵弾200発＋敵40体でも一般的なPCで60fpsを保つ。画面外のオブジェクトはすぐ消す
